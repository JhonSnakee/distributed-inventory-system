# Technology Stack & GenAI Integration

## Backend Technology Stack

### Core Technologies
- **Runtime**: Node.js 18+ (async/event-driven, good for I/O intensive operations)
- **Framework**: Express.js (lightweight, fast prototyping)
- **Database**: SQLite with better-sqlite3 (synchronous operations, simple deployment)
- **Testing**: Jest + Supertest (comprehensive testing framework)

### Architecture Patterns
- **CQRS**: Command Query Responsibility Segregation for read/write separation
- **Event Sourcing**: Conceptual model for audit trail and consistency
- **Optimistic Locking**: Version-based concurrency control
